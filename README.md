# Варты — хранители Нижневартовска

Сказочный сайт о семье бронзовых фигурок-хранителей Вартов: легенда, герои, «добрые знаки» и маршрут по городу.

## Запуск

```bash
npm install
npm run dev
```

## Где что лежит

- `data/heroes.ts` — герои, желания и точки маршрута (новый рисунок или адрес добавляется здесь)
- `data/lore.json` — тексты краеведов о каждом члене семьи
- `components/` — интерактивные блоки: небо, семья, «потри кольцо», схема маршрута
- `public/img/` — рисунки, силуэты и логотип
